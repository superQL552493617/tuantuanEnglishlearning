# 小团学英语

一个 iOS 视频播放 App（第一版开发中）。

## 功能（第一版）
- 在 App 内点“+”，从“文件”App 选视频，复制进 App 自己的目录
- 播放系统支持的视频格式，自带 AirPlay 投屏和画中画
- 三种播放模式：列表循环 / 单个循环 / 随机播放
- 缩略图、时长、文件大小显示；不支持的格式会标注并自动跳过
- 左滑删除；后台和锁屏继续播放声音

## 技术
- SwiftUI + AVKit
- 最低系统：iOS 17

## 后续计划（第二版）
- MKV、AVI、FLV、RMVB 等格式支持
- DLNA 投屏
- 电视版
- 断点续播、倍速播放、电脑通过 WiFi 上传视频
